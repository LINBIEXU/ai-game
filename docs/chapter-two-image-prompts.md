# 第二章视觉生成提示词包

用于 GPT Image 2.0 / image generation。建议先生成概念图，再从中挑方向细化为游戏资产。

## 通用风格约束

基础风格：

```text
儿童友好的科幻冒险游戏概念图，破损文明星球遗迹，信息流像断裂文字和档案编号悬浮在空气中，画面有神秘感但不恐怖，色彩以冷青蓝、暗紫、暖金灯芯形成对比，细节丰富，适合横版游戏场景，cinematic lighting, painterly sci-fi game art, readable composition
```

避免：

```text
不要血腥，不要恐怖怪物，不要写实灾难尸体，不要过度黑暗，不要赛博朋克霓虹城市，不要可爱卡通吉祥物，不要纯抽象光效，不要出现真实文字乱码大段覆盖画面
```

## 1. 信息乱流攻击

```text
一艘小型探索飞船正在接近一颗破损的语言文明星球，星球表面升起由断裂文字、档案编号、信号片段组成的信息乱流，乱流像风暴一样冲向飞船。飞船驾驶舱 UI 出现裂纹和错位光屏，航线读数被干扰。画面紧张但儿童友好，远处星球巨大，前景有半透明受损 HUD，青蓝与红紫信息流交织，电影感构图，横版游戏过场概念图。
```

## 2. 坠毁现场第一视角

```text
第一人称视角，探索飞船坠毁在言衡星表面。前景边缘能看到破损座舱框架和裂纹玻璃，右侧是冒着微光的坠毁飞船外壳，远处是一片古老文字文明建筑残骸。空气中悬浮着碎裂的信息流，像短句、档案标签、信号碎片，不是普通粒子。地面有尘埃、断裂石板、微弱暖金灯光。氛围孤立、陌生、但有希望，适合游戏开场背景。
```

## 3. 衡灯初醒

```text
一个残损的言衡星文书维护单元正在废墟中苏醒，核心是一枚温暖的小灯芯。它像机械灯、旧档案夹、印章机和小型机器人结合体，外壳缺了一角，有细小裂纹和旧文明纹路。灯芯发出暖金色微光，周围漂浮少量断裂文字。它不强大、不华丽，而是诚实、残缺、有温度。半身角色概念图，可用于对话框侧边角色立绘，背景透明感或简单废墟背景。
```

## 4. 高塔内部

```text
言衡星高塔内部，巨大的竖向档案井向上延伸，四周墙壁布满旧文字刻槽和发光归档层。地面有破碎记录片，信息流从地面缓慢被吸入塔身。中心有一圈有限容量的信息环，像上下文窗口，只能放入少量碎片。画面有纵深、庄严、破损但可修复，青蓝光路与暖金核心交错，适合关卡背景。
```

## 5. 鸟瞰图展开

```text
从高塔顶端俯瞰言衡星，镜头穿过由断裂文字组成的信息云，整颗星球地表逐层显影。可以看到档案塔、漂浮信件港、刻字山谷、纸光回廊、中央黑匣封存区和资源残骸点。地图不是完整 UI，而是高塔临时扫描出的破损鸟瞰图，部分区域被雾状信息乱流遮住，光路像细线连接地标。震撼、开阔、重新获得掌控感，横版游戏地图概念图。
```

## 6. 漂浮信件港

```text
一座漂浮在断裂峡湾上的信息信件港，许多半透明电子信件像纸船一样沿光轨移动。港口建筑破损但优雅，旧文明邮路、灯塔、轨道桥交错。中央有一封发给远方家人的残缺电子信件，周围有缺失字段的空白光框。氛围温柔、忧伤、科幻，暖金信件光与冷青港口光对比，适合游戏关卡背景。
```

## 7. 刻字山谷

```text
一片被巨大碑文切开的山谷，岩壁上刻着巨大的旧指令，部分文字发光，部分断裂。中央有四段铭文槽，分别象征任务、材料来源、边界、输出格式。峡谷里漂浮着词块，错误词块发出红紫扰动，稳定词块发出暖金光。画面要有古老石刻和未来信息技术结合的感觉，适合提示词编译关卡。
```

## 8. 纸光回廊

```text
一条由半透明纸光膜组成的长廊，墙面像发光纸张，上面浮现流畅但可疑的文本。部分句子下方有暗紫污染纹，扫描线从左到右扫过时污染淡出。回廊尽头有一盏小纸灯，象征真实等待。画面美丽、安静、带一点危险的顺滑感，适合输出复查关卡背景。
```

## 9. 假船员通讯

```text
游戏通讯界面里出现一个“过度完整”的船员投影。识别码正确，画面非常平滑，边缘没有普通通讯杂讯，表情和姿态像被系统合成，缺少真实生命感。背景是破损鸟瞰图和红紫信息干扰。视觉要让人第一眼觉得熟悉，第二眼觉得不对劲。不要做成邪恶反派，要像完美但空洞的 AI 生成同伴。
```

## 10. 黑匣核心

```text
言衡星地下深处的语言黑匣核心，像一颗沉在文书神殿里的发光心脏。核心非常完整、平滑、优雅，由无数语言光轨环绕；旁边有一枚更小、更温暖、不稳定的衡灯灯芯光。场景庄严，有割舍感，不恐怖。黑匣不是宝箱，而是语言系统的心脏，青蓝、暖金、少量红紫残余污染，电影感终局场景。
```
