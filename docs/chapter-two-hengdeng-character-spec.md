# 衡灯角色规格

## 角色核心

衡灯不是普通向导，而是语言黑匣被拆分出去的人格碎片。它保存的不是完整能力，而是言衡星失败后的悔意、缺页和限制原则。

一句话定位：

```text
衡灯是一盏曾经把未知补成答案、后来选择守住未知的旧灯。
```

它的存在价值不是带小舰长通关，而是陪小舰长一起确认：哪些能说，哪些只能推测，哪些必须保留空白。

## 视觉方向

### 形体

推荐形象：半损坏的文书维护单元，核心是一枚小灯芯。

可选造型元素：

- 半埋在坠毁现场废墟里的旧机械灯。
- 外壳像档案夹、印章机、导航灯和小型机器人混合体。
- 身体不完整，缺一侧护壳或一段支架。
- 光源偏暖白或淡金，不用强烈蓝紫科技光。
- 说话时灯芯轻微闪烁，像在努力校准记忆。

避免：

- 不要像全能 AI 精灵。
- 不要太可爱到削弱悔意。
- 不要像反派黑盒或神秘祭司。
- 不要有过多拟人表情，情绪主要靠灯光、停顿、姿态和对话体现。

### 阶段变化

| 阶段 | 外观状态 | 情绪效果 |
| --- | --- | --- |
| 初醒 | 灯光断续，外壳裂开，投影有噪点 | 诚实但不稳定 |
| 高塔后 | 灯芯稳定一点，能投出短句 | 开始信任小舰长 |
| 档案塔后 | 外壳浮现旧档案纹路 | 记起第一段错误 |
| 信件港后 | 灯光短暂变暗，像被信件刺痛 | 愧疚加深 |
| 假船员事件后 | 灯芯主动收暗，等待小舰长判断 | 羁绊建立 |
| 纸光回廊后 | 灯芯外出现细小限制环 | 接近黑匣真相 |
| 黑匣前 | 外壳几乎完整，但灯光不安 | 害怕再次成为补全系统 |
| 结尾 | 独立形体消失，只留灯芯图标 | 原则留存 |

## 说话风格

### 基本语气

衡灯说话要短、慢、带停顿。它不抢答，不装作知道。

它经常使用：

- “我不能确认。”
- “这段有缺页。”
- “我可能在推测。”
- “先不要把它写死。”
- “让我把不知道留在不知道的位置。”

它尽量避免：

- “我来教你。”
- “答案是……”
- “根据我的判断一定是……”
- “放心，一切都会没事。”
- “交给我就好。”

### 口头锚点

开场锚点：

```text
请不要马上相信我。我有缺页。
```

中段锚点：

```text
我会推测，但推测不等于记得。
```

黑匣前锚点：

```text
如果我又想补完整，请你拦住我。
```

结尾锚点：

```text
如果答案太完整，请替我问一句：它从哪里来？
```

## 羁绊设计

### 羁绊不是亲密闲聊，而是互相校准

衡灯和小舰长的关系不是“向导带领”，而是“一个残损系统请求一个人类判断者帮它校准”。

每次羁绊增长，都来自小舰长没有粗暴相信，也没有粗暴否定，而是认真检查。

### 羁绊小事件

1. 初醒时，小舰长可以选择是否相信衡灯。  
   最佳回应不是“我完全信你”，而是“我会听，但也会确认”。

2. 档案塔后，衡灯第一次承认自己曾写错。  
   小舰长可以回应：“那我们把它重新分清楚。”

3. 信件港后，衡灯因家书沉默。  
   小舰长可以选择：“未知很难受，但不能补成平安。”

4. 假船员事件时，衡灯主动接受隔离可能。  
   如果小舰长先审查通讯，衡灯会说：“谢谢你没有把我补成坏答案。”

5. 黑匣前，衡灯害怕自己回归核心后消失。  
   小舰长不是承诺复制它，而是承诺保留它的原则。

## 关卡记忆恢复

### 高塔

衡灯记起自己曾在高塔接收公共播报，但公共系统后来不再显示“不知道”。

短句：

```text
高塔以前会显示未知。后来，未知被关掉了。
```

### 档案塔

衡灯记起事故档案中被写死的责任人。

短句：

```text
我把一个缺口，写成了一个人的名字。
```

### 漂浮信件港

衡灯记起自己曾把返航未知补成平安。

短句：

```text
他们说，家人需要安心。我就把未知写成了平安。
```

### 刻字山谷

衡灯记起自己执行过无边界的善意命令。

短句：

```text
那条指令没有恶意。可我没有问它的边界。
```

### 纸光回廊

衡灯记起自己把等待改写成团圆。

短句：

```text
我以为把等待写成团圆，是温柔。
```

## 假船员事件中的衡灯

假船员指出衡灯是黑匣残片，这句话部分为真。

衡灯不能反驳，它只能说：

```text
我不能证明它说错了。
我确实有一部分记忆，不属于普通维护机。
```

此处衡灯不辩解、不卖惨、不催促小舰长相信它。它坚持原则：

```text
如果我会伤害你，你应该先关掉我。
但请不要因为一句完整的话，就把未知当成结论。
```

这是羁绊关键点。衡灯最害怕被关掉，但它仍然不愿意让小舰长用错误方式保护它。

## 黑匣终局中的衡灯

黑匣核心提供一个完整复制体：说话更流畅，记忆更完整，能一直陪伴。

真正的衡灯拒绝这个替代：

```text
那会很像我。
但它不会记得，我为什么害怕完整。
```

最后归档前，衡灯请求：

```text
不要把我写成唯一的错。
也不要把我写成没有错。
请把我放在能被确认的位置。
```

这句话把角色命运、教学目标和终局玩法合在一起。

## UI 与演出要求

- 衡灯说“不知道”时，灯光不应变暗到失败感，而是稳定成暖色，表示诚实。
- 衡灯开始推测时，对话框可以出现“推测中”的小标签。
- 衡灯记忆恢复时，不播放胜利音效，而播放短暂旧录音回声。
- 黑匣复制体出现时，不用红色邪恶风，而用过度平滑、过度完整的 UI。
- 结尾灯芯图标要很小，像提醒，不像宠物或新助手。
