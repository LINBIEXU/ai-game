# Chapter Two Gameplay Overhaul

Current goal: rebuild chapter two so the player feels like they are surviving and repairing Yanheng Star, not reading a lesson deck. Each level must have a distinct player verb, visible world feedback, pressure, and a reason to matter in the blackbox fight.

## Design Spine

- Every level prepares one ability or emotional condition for the central blackbox battle.
- Learning ideas must appear as game verbs: route, probe, dock, engrave, scan, quarantine, hold, ignite.
- The UI is diegetic field equipment. Avoid generic explanation cards as the primary experience.
- Failure should change the scene or pressure meter, not just show "wrong answer".
- The blackbox battle is the chapter's boss fight: prompt injection, boundary rewrite, crew return, Hengdeng override, longfire choice, restoration.

## Level Modes

| Level | Game Mode | Primary Verb | Blackbox Payoff |
| --- | --- | --- | --- |
| Crash Site | Cinematic survival crawl | Breathe, check, move | Establishes that no response is not a conclusion |
| Semantic Dispatch | Request-flow routing | Route requests under noise | Teaches task type before response |
| Evidence Well | Probe-based source scan | Drop probes, recover evidence | Teaches source strength and unknowns |
| Boundary Beacon | Permission-line defense | Calibrate action boundaries | Prevents AI overreach in fake signal and blackbox |
| Archive Tower | Vertical investigation | Separate fact, inference, unknown, forbidden | Rebuilds the archive gate |
| Letter Port | Time-slip delivery repair | Return, preserve blanks, reconnect tracks | Rebuilds the delivery gate |
| Engraved Valley | Inscription forging | Forge prompt structure and see output consequences | Rebuilds the instruction gate |
| Paper Corridor | Semi-transparent roguelike | Read route risk, collect relics, scan fluent text | Rebuilds the expression gate |
| Fake Crew Signal | Live comms interception | Pin, mark unknown, quarantine, hold | Sets up true crew return and prompt-injection stakes |
| Central Blackbox | Boss trial and longfire climax | Reconnect abilities, refuse replacement, ignite | Resolves the chapter theme |

## Current Rewrite Pass

- Semantic Dispatch is now a request storm: the player routes incoming requests into organize, verify, ask, or human-judgment tracks.
- Boundary Beacon is now a permission defense: the player locks requests into assist, ask, human, or forbidden zones.
- Fake Crew Signal is now a live interception: the player marks individual comm packets with field tools, then chooses an audit reply.

## Next Rewrite Targets

1. Make Archive Tower less like a card sorter by turning room traversal into a vertical investigation loop with persistent tower pollution.
2. Make Letter Port's time-slip more interactive: the past scene should alter what fields are available in the present.
3. Make Engraved Valley's prompt forging show generated consequences directly in the landscape before validation.
4. Make Paper Corridor route selection more roguelike: partial route preview, relic risk, and pressure carryover.
5. Rework blackbox phase one so the four abilities fire as boss counters instead of separate worksheet gates.
